## What is included

| Stage | Work | Output |
|---|---|---|
| P0 | Understand the brief | Task confirmation and deliverable-purpose mapping |
| P1 | Research and evidence | Findings tied to decisions, sources and gaps |
| P2 | Insights and opportunities | Testable interpretations, communication opportunities or brand positions |
| P3 | Communication strategy | Different persuasion routes, a recommendation and fallback conditions |
| P4 | Creative concepts | Distinct mechanisms and representative creative samples |
| P5 | Communication and execution | Touchpoint roles, schedule, resources and unresolved dependencies |
| P6 | Proposal and delivery | A decision-oriented narrative supported by evidence and work |
| P7 | Review and maintenance | Separate records of adoption, execution and measured outcomes |

Four Markdown skills cover P0, P1, P2 and P4. P3, P5, P6 and P7 are covered in the main workflow and templates. Keep the complete `skills/` directory because the modules share references.

## Start

Read the workflow, copy the blank templates into a private project, then give your AI assistant the current brief and the relevant stage instructions. See [USAGE.md](USAGE.md) for prompts. No API key or software dependency is required to read or reuse this repository. Host-specific skill discovery and installation vary; Markdown instructions are the portable fallback.

Separate observations, hypotheses, brand positions and fictional expression. An approved direction does not turn a hypothesis into evidence. A limited adaptation task does not need the entire process. Missing evidence constrains dependent conclusions, rather than forcing all work to stop.

Public edition **v1.0.0**, based on internal workflow v1.16 and its shared guidance. The public package contains reusable methods and fictional examples, not client briefs or private project conclusions. It is not a validated guarantee of creative quality, pitch success or commercial outcomes.
