# AERO 核心创意

跨阶段执行 [创造性推导与工作流维护标准](../aero-brief-analysis/references/creative-reasoning.md)。Big Idea 不等于广告语或拍摄手法：它应改变观众看待品牌/商品的方式，并能生出具体作品；不能用更响的标题掩盖无事发生。

## 任务与入口

从一条已推荐的传播策略出发，提出少量真正不同的创意机制，让客户能判断为什么有人愿意看、参与或记住，以及品牌和产品怎样使它成立。开始前读取本项目的P0任务与责任边界、P1证据及反例、P2洞察或机会假设的状态、P3策略及评审状态，并核对产品事实、预算、市场、形式和资源条件。只读取当前任务需要的材料。

P3尚未获批时可以做**条件性方法试跑**，注明所依赖的策略，不改变项目阶段或对外口径。P2没有合格洞察时，可以基于“传播机会假设＋缺证清单”探索创意，但不得把假设写成已证实的人群动机。策略本身不成立时返回P3；仅表达不足时留在P4调整。

## 创意工作

1. **锁定创意简报。** 用一页以内写清：要改变谁的什么判断或行为、P3选定的说服逻辑、品牌与产品必须证明什么、必选与禁用项、目标市场和可用形式。将已证事实、策略判断、待核实输入分别标记。
2. **展开机制。** 尝试不同的构造方式，例如角色关系改变、可公开复验的产品证明、由受众参与推进的行动、叙事视角转换或媒介本身成为创意。方法用于打开方向，不要求凑齐类别或数量。通常保留2–4个有可比性的方向；若只剩一个或没有合格方向，如实交付原因。
3. **区分创意层级。** 对每个方向判断它是品牌平台、阶段性Campaign、事件/内容机制，还是单支片子或某渠道执行。换名称、达人、画面风格或投放平台，不算新的核心创意。
4. **做成可审的方向卡。** 每张卡写一句话创意、受众为何看/参与、关键动作与转折、品牌和产品不可替代的作用、至少一个代表性样本，以及如何按本项目范围延展至事件、影片、KV、短内容或行动入口。未在任务范围内的形式不自动加入交付承诺。
5. **反向审查。** 比较策略贴合度、品牌专属性、产品可见的因果、记忆点、跨形式生命力、本地文化适配和可执行性。逐张提出最强异议：去掉品牌是否仍成立？产品只是在结尾露出吗？是否依靠未经批准的宣称、版权、达人、场地、安全条件或预算？有没有与已知竞品作品过近的表达？区分需补证的问题与纯创意判断，不用模型自评分代替用户评审。
6. **收束与交接。** 给出优先测试方向和理由、被淘汰方向的具体原因、要制作的最小样本及验证问题。用户选定核心创意后，再向P5交接资产角色、渠道任务、资源条件、预算输入和风险；未选定前不把样本写成正式方案。

## 交付标准

页面最前面只放结论、当前状态及最多三项会改变方向或成本的决定。详细方向卡和比较表放在后面。每个候选至少回答“为什么是这个品牌、这个产品、这个人群、此时此地”，并展示一个可拍、可画或可执行的动作。影片、KV或社媒可以是代表样本，但它们必须承载同一机制，而非互相无关的漂亮素材。

检查上游影响：如果创意要求改变受众、产品事实或说服来源，标明需要退回的P0-P3节点及受影响旧稿；不要悄悄改写已确认前提。创意概念通过不等于资源、合规、预算或效果已验证。
