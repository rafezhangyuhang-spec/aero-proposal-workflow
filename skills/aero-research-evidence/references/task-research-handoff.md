# P0 到 P1：任务与研究衔接规范

版本 1.2 · 2026-10-10。共享执行规范；方法选取依据见同目录 method-fit.md。本规范不改变客户要求，也不把研究计划写成已完成研究。

## 共同输入

优先使用项目已有的数据文件或任务登记，不另建重复背景。至少记录：当前 P0 来源及版本、Brief 原件、历史截止/市场、各项交付与目标、客户要求/我方建议/未知、明确条件与概念自由、变更影响。用稳定任务编号连接材料和判断，编号不固定为本案例的数量。

P1 每次开工先读取当前登记；新假设不能改写客户任务。补回漏项需回到原件核对并同步 P0；建议改客户目标则说明理由并交决策人确认。各步骤共享事实背景，不共享预设答案。

宣告资料缺失或要求用户重传前，先在当前任务已知的项目来源中查找附件。找到后分别确认项目归属、版本、内容和可支持的判断；目录月份、文件元数据不单独证明收件时间。按真实内容更新 P0/P1，参考图不作实物、系列清单不作逐款 SKU、资料自述不作效果验证。缺口只限制依赖它的结论，已有基础的部分继续条件探索，不把资料齐全设为全案启动门槛。

## 先覆盖，后深挖

检查自己、品牌、产品、竞争、市场、人群六个视角，并跨视角覆盖所有交付：
- 自己：我方职责、可证明的能力与资产、思维惯性；没有公司作品证据，不自封独特优势。
- 品牌：经营意图、主张、识别资产、历史作品与公众理解，彼此区分。
- 产品：实物特征、使用/搭配/赠送等情境、选择与放弃；明确规划系列和具体 SKU 的差别。
- 竞争：购买替代、注意力竞争、跨品类表达参照，分开标注；研究实际作品，不只收口号。
- 市场：市场与品类结构、时间变化、文化和媒介环境；热点不自动等于需求。
- 人群：生活、情绪、语言、使用、选择与分享，不只购买障碍；单点片段不拼成完整人的旅程。

这是覆盖检查，不是六份报告或固定代理数量。可合并、不适用时解释。深度按对任务的重要性和未知风险分配，不按搜索结果多少分配。通常先看品牌主任务，但遵循项目实际优先级。

## 一条材料如何进入判断

先写“哪项交付的哪个选择尚不能判断”，再确定研究对象与材料，不从关键词搜索开始。内部用一行串起：任务 → 未知 → 看什么 → 不同发现怎样改变选择。已有材料先复用并核对适用性，不无差别重搜。

问题不能偷带结论。例如先查人们怎样描述品牌，而不是预设他们只认便宜；先查商品在什么情境有吸引力，而不是预设购买是为了做自己。

研究可能影响表达重点、选品、人物作用、识别方式或触点分工；此处列的是可能改变的选择，不是提前推荐策略。作品观察、审美与跨领域联想也可提供机会，但要说明任务关联，不冒充人群动机。六视角用于查漏，不是六份报告目录。

每条关键材料写：来源与可用时点 → 实际观察 → 服务的任务编号 → 我方解释 → 最强其他解释或限制 → 会改变的判断。支持、反例和未观察到分开。不能关联具体任务的材料留作旁支灵感，不支配研究主线。

允许先提出大胆假设，但未覆盖核心委托前不把其中一条设成全案主轴。解释可以共存，不强造互斥；没有心理矛盾也可以形成审美、幽默、品牌记忆等机会。

## 研究综合与出口

交给下一步的是研究判断，不是资料摘要：**看到了什么具体情况 → 对本案意味着什么 → 哪个选择值得进入 P2 检验。** 每个判断附任务编号、可定位来源及重要限制。只能形成机会却不能证明动机时，写“表达机会”或“待检验解释”；未研究完不把问题改写成结论。

停止与交接依据：核心任务有判断基础或明确缺口，关键解释已检查其他可能，继续收同类材料不太会改变当前选择。不是搜到固定数量案例或凑齐六个标题。不要求所有疑问消失或一律开展大规模调研；缺口影响哪项选择，就限制哪项结论。

对每项交付写：任务是否保持、已有何支撑、哪些假设值得试、哪些问题仍未知、下一步可以做什么。再检查跨任务的共性；不能为了统一提案而抹平不同任务。

创意课题是研究后的问题定义，不是口号、故事或既定策略。P1 给出暂定课题及限制，P2 检验洞察/机会，P3 再作策略选择，不额外制造一轮强制审批。

出口可为：继续补查、可条件性交接、建议回到 P0 改题。核心任务缺证时，不用次要任务的丰富素材冒充全案完成；允许对已有基础的部分继续探索，缺口明确，不要求所有资料齐全。

## 展示与验收

主页只呈现当前可用判断及下一步，事实、我方建议和待证问题明确分开。研究设计、覆盖缺口、证据与方法展开查看，历史稿不进入当前导航。

验收四问：每项核心交付是否覆盖或解释缺口？关键结论能否追溯到具体任务和材料？有无把局部样本冒充全案答案？换一种研究发现，哪些判断会变？结构检查通过不等于洞察或创意通过。
