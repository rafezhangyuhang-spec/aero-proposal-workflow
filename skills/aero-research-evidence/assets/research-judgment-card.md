## 任务覆盖

先确定研究要帮助判断什么，再收集资料。以下为内部记录，不全部放首页：

| 关联任务 | 尚不能判断的问题（不预设答案） | 先看已有材料／再补什么 | 不同发现会改变哪项选择 |
|---|---|---|---|
| | | | |

| 任务编号与交付 | 要做、注意、表达什么 | 自己/品牌/产品/竞争/市场/人群覆盖 | 已知与未完成 | 优先补什么、为什么 |
|---|---|---|---|---|
| | | | | |

六视角可合并或标不适用，不机械填满；必须解释核心交付缺口。

## 关键材料
| 证据编号 | 来源、日期、市场、对象、口径 | 实际观察 | 关联任务 | 解释、反例与限制 | 改变什么判断 |
|---|---|---|---|---|---|
| | | | | | |

材料适用性：在来源栏注明实际读到正文、搜索摘录还是作品画面；区分原始发表时间与后加内容、同一来源的转载、品牌与同集团其他品牌、相邻产品形态。无法确认的材料可生成问题，不支撑定论。购买前未选、买后不喜欢和弃用分别记录；传播装置、参与激励、自发分享与效果分别判断。

## 按任务综合

需要重定义问题时，先写四句：原先怎样理解 → 新解释是什么 → 哪些材料使它值得考虑 → 若成立，会改变什么选择。再写最强其他解释或可区分两者的补查；不要先把它压成口号。按需使用，不强制每条资料各填一份。
| 任务 | 有依据的判断 | 值得探索的假设与其他解释 | 暂定创意课题 | 下一步与所需材料 |
|---|---|---|---|---|
| | | | | |

竞争机制：受众与目标 → 具体作品/体验 → 品牌关联 → 参与或行动路径；效果有独立依据才写。
改变当前任务建议：无则不填；有则注明原要求、新建议、理由、决策人及下游影响。
自己：记录我方可证明贡献与惯性，不发明公司优势。
验收：覆盖是否漏项；判断能否追溯；局部有无冒充全局；替代发现能否改变判断。
