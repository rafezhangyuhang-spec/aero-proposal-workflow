# 洞察、传播机会与品牌立场

公开版补充说明，与当前 P2 Skill v1.2 一致。“证据—裂缝—下注—兑现—回收”是可选推理路径；并非所有项目都需要心理矛盾。

## 先决定在判断什么

| 类型 | 需要说明 | 不能冒充 |
|---|---|---|
| 人群洞察假设 | 具体人、具体处境、行为关系、新解释与替代解释 | 已证消费者共识 |
| 传播机会 | 哪种信息、观察或表达可能值得观看，如何关联任务 | 已验证的观看、分享或销售效果 |
| 品牌立场 | 品牌选择站在哪边，产品或行为怎样承担 | 目标人群已经普遍认同的事实 |

## 从材料到新解释

1. 分清实际观察、真实原话、解释和未知；记录来源、时间、市场及范围。
2. 寻找常识未解释的关系、意外行为或被忽略的可能。人说与做不一致可以成为线索；不同人的材料不能拼成同一人的矛盾。
3. 比较常识解释、最强反解释与值得检验的新解释，说明各自会改变什么选择。类比用于发现，不负责证明。
4. 检查品牌资格与差异：能否兑现这个回应？怎样被认成这个品牌？两问不相互替代。
5. 写明可区分解释的证据、推翻条件及回退路径，再决定保留、收窄、降级或撤回。

没有直接人群证据时，明确暂无合格人群洞察。仍可交传播机会或候选品牌立场，并条件性探索创意；不要用格式完整冒充研究完成。

## 观点尺度的用途

0 事实复述；1 常规含义；2 具体解释；3 品类重构；4 文化挑衅；5 无依据幻想。

尺度只帮助检查经验性主张跨出了多少证据，不是创意分数，不以追求高档为目标。虚构作品、幽默、审美和品牌价值选择不按经验事实的尺度压缩想象。事实主张越大，需承担的证据责任越大。

## 四项常见断点

- 专家能证明“产品能”，不自动证明观看者会理解成“我能”。
- 心理学机制或跨行业研究可以提示解释，不等于本市场人群证据。
- 指定达人、IP 或媒介是条件，不是倒推洞察的理由。
- 方向被采用不会把假设升级成事实；新增证据才改变证据状态。
