# 从 Brief 措辞到任务判断

用于 P0。借鉴语义、语用与沟通意图分析，不做客户心理诊断。参考 [Pragmatics](https://plato.stanford.edu/entries/pragmatics/index.html) 和 [Implicature](https://plato.stanford.edu/entries/implicature/)；以下表格为团队工作方式，不宣称是经验证的心理量表。

先判断一句话在做什么：描述背景、提出目标、要求交付、推荐手段、提供资源，还是规定评审标准。然后读它的限定词与上下文，例如必须、希望、建议、可考虑、优先、从什么到什么，以及同时出现的目标与限制。

重要措辞按现有依据表记录：原文和位置 → 明确要求 → 可能的沟通意图/顾虑 → 其他解释 → 对交付或研究的影响。重复强调可以提示重点，不等于按词频排序；模糊目标不能自动转换为预算、销量或成功保证。模板语言、多位作者和内部规范都可能解释措辞，不反推客户的性格、过去失败或组织压力。

最终写清三件事：客户希望解决的问题、我们应交付的作品/服务、这些作品希望造成的变化。交付存在不证明效果发生；说出目标也不证明当前受众处境。各作品条件分别归属，不能把产品片的媒介或人物要求套到全案。

人话检查：客户看完能否指出我们理解错了哪件事？若只能读到“赋能品牌、强化情绪、打造记忆”，还不能交接。也不能为了具体而在任务确认中先写口号、剧情或锁定心理洞察。
