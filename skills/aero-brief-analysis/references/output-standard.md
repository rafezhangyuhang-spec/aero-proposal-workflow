# P0 任务确认统一产出标准

版本 1.2 · 2026-10-09。适用于广告、品牌和营销 Brief、任务重审与客户改题。以一句准确的任务确认作为首要输出，复杂任务按需展开。跨项目有效性仍待实跑；这是内部工作标准，不代表客户批准或行业统一规范。

## 目的与边界

准确理解委托，主动判断值得解决的问题，提出可被修正的探索入口，为后续研究提供焦点与想象空间。P0 不是 Brief 复制、执行风控清单，也不是缩短版策略或创意。

统一的是团队必须明确知道的六件事，不是创意形态、假设数量或创作路线。“背景、目标、任务、条件、研究问题、反向检查”保留为内部覆盖检查，不作为另一套用户表单。

## 输入与思路

按需使用 [Brief 语言与意图分析](brief-language-reading.md)，从要求强弱、限定范围、目标之间的关系判断客户要解决的问题。不把措辞推断写成心理事实；分别列作品交付、期望变化与评价方式，保留可修正的解释。

输入为原始 Brief、已有附件、已确认补充、最新用户决定及项目阶段。区分客户要求、客户对市场的判断、外部事实、我方推断和未知；缺失附件如实记录，不假装读过。

先理解客户为何做、希望改变什么、买哪些交付；再检查问题是否问窄、目标是否冲突、默认前提是否成立；最后提出能影响研究的开放问题。可往返修正，不要求先找到洞察才能判题。

跨学科联想可用于改变尺度、视角、条件、关系或因果提问。说明“借用了什么思考方式、打开了什么问题”，不以学科名词装饰结论，不把动物研究、数学类比或文学表达当目标消费者证据。无需每个项目凑齐学科。

## 必交产物

**A．先给一句准确的任务确认，按需附任务与目的表、关键待确认。**

形成过程：读有效输入 → 区分要求性质 → 对齐每项交付与目的 → 压缩表达 → 回到原文反查。参考句型：“客户要〔委托成果〕：〔工作 A〕用于〔具体目的 A〕，〔工作 B〕用于〔目的 B〕，并提供〔必要配套〕。”句型不是必填表，没有依据的内容不补造。

明确提案与制作、目标与交付、要求与建议。必要配套不能为简短而遗漏；形式开放的委托不能擅自指定形式。复杂任务允许一句总述加表格，不以语法上的一句话牺牲准确性。用户只要一句时不附完整流程。

以下六项作为内部覆盖检查及按需展开的支持信息，不再强制六栏同时上屏：

1. **为什么做：** 客户发起委托的原因与期望变化；客户对市场的判断不自动当作事实。
2. **交什么：** 核心作品或服务；完整配套交付、规格和档期放详细记录。
3. **分别改变什么：** 希望影响谁的什么认知、感受或行为；多种作品分别承担什么任务。客户要求与我方分工建议明确区分，不强行拆分本来相同的任务。
4. **独立判断：** 指出影响解题的任务关系、目标冲突、遗漏机会或待检查前提，并说明理由与后果。不能只是换词复述目标，也不要求惊人的人性洞察；可以判断原题合理，但须说明判断依据。
5. **关键未知：** 只列答案不同会改变任务理解或解题方式的问题，详细记录写明如何改变判断。大胆假设可放探索记录，不作为强制首屏栏目。
6. **答对标准与待确认：** 写本案作品回应任务的标准、必须由决策人确定的事项；区分作品判断与市场效果。另记任务状态与下一步，不用文件完成代替批准。

没有适用内容时不虚构冲突。纯规格适配用简版；只有目标的 Brief 保持形式开放；重要歧义或冲突单列待确认。不要强制三条假设、深层矛盾、统领所有作品的唯一问题或跨学科引用。

**B．详细记录：折叠或另页，支撑但不挤占任务卡。状态和版本也是记录的一部分，不另造用户必填表。**

- 背景与目标：客户为何做、希望影响谁的什么认知/感受/行为，目标有何主次或冲突；不同作品可以承担不同任务。
- 任务与边界：核心/配套交付、受众和市场、时间要求、必选条件、创作空间。概念探索与执行委托区分。
- 判断与来源：原文页码或补充出处、我方推理、替代解释、重要未知。
- 研究交接：问题、提出理由、希望观察什么、不同发现会怎样改变对任务的理解。不是只找支持材料，也不是预填下一阶段答案。
- 评价与版本：概念质量、客户确认、执行验收、市场效果分别记录；修订原因、被替代版本、受影响下游稿件。

**状态与交接：不以文件产出替代批准。**

任务状态用“待讨论／已确认可交研究／需重新对齐”，注明确认依据与日期；没有确认就不编确认人。探索状态另记“待研究／有初步依据／需补查”，允许任务确认与假设待证同时存在。用户只要求任务确认时，停在 P0，不自动展开策略或创意。

## 六项验收

1. **准确：** 交付、目标和明确条件可追溯，没有漏题、扩题或暗中换题。
2. **具体：** 能说清本案希望发生什么变化，而非只有适用于所有品牌的好看、出圈、记忆目标。娱乐或品牌显著性若本就是客户目标，可以保留，不强加认知升级。
3. **独立：** 至少有实质判题，而非改写客户形容词；依据不足时可以主张和追问，不必等待全量调研。
4. **开放：** 未把探索入口变成完整方向池，未指定情节、口号、媒介机制、统一洞察或必有社会冲突。幽默、感官和想象均可成立。
5. **逻辑：** 购买驱动、品牌目标、作品机制分开判断；问题能被不同发现修正。不把可共存的解释伪装成互斥竞争。
6. **可读且可交接：** 首屏能独立复述任务，摘要不增加前提、不改变疑问语气；下一步研究能改变判断，旧版本与当前状态清楚。

这些是内部质量检查，不要求每个项目在首页复述规则，不合成机械总分。实质错误先修；假设待证不是自动不通过理由。

交接验收：让未参与讨论的人只读任务卡，复述为什么做、交什么，区分客户要求与我方建议，并说明先研究什么、不同答案改变什么判断。创意人员应清楚任务，同时仍能提出完全不同的作品。未实际开展独立复述或评审就标为未测，不以自检代替团队验证。

## 创作自由与条件处理

概念阶段可按项目约定将预算、权益、场地与技术后置，集中记录，不逐段打断想象；已明确的硬条件仍如实保留，不能从单个项目推导所有项目都可忽略预算。涉及执行承诺时再核可行性与授权，不把设想当资源已落实。

品牌目标不要求逐条说理或产品演示。相反，娱乐或记忆做得好也不自动证明其他客户目标完成。是否要改变目标与怎样自由表达，是两项不同决定。

## 可选交叉评审

任务争议较大或用户要求时，用三种立场检查：品牌负责人守护任务与目标；创意总监检查焦点、启发性与隐形定题；消费者与文化研究者检查生活关联、投射与解释空间。它们是模拟视角，不是真实客户或受众。

先独立阅读相同版本，每人只报关键问题、原文依据、后果及最小修改，再交叉质询并记录分歧。主审判断，不以多数票或一致意见当作有效性证明。多智能体仅在获得授权时调用，普通项目不强制三人审。

## 工作流接入与回退

P0 使用本标准与配套模板；P1 接收未锁答案的研究题，不只寻找支持；P2–P4 不得把 P0 探索入口当作已选洞察或创意。这里规定交接语义，不改写下游各阶段方法。

交接需在项目已有登记中保留当前 P0、原始输入及各交付的稳定任务编号，写清要做什么、注意什么、表达什么，并区分要求/建议/未知。P1 读取完整委托开展覆盖检查，不能把 P0 的几条探索问题当全部研究范围；研究后问题定义由综合形成，改客户目标需确认。

用户改题或评审发现实质问题时：新增任务版本，记录原因和影响；保留有效历史材料，将受影响策略/创意标为待重审或不再沿用；同步阶段文稿、看板数据和生成页面，不只在聊天口头撤回。

通用标准、项目任务、未证假设分开存放。任务卡中不混入本标准的长篇教程。跨项目复制时使用空模板，不把案例的三条假设作为默认答案。

看板首页仅发布当前有效、可直接使用的信息。旧稿、被撤回的推荐与版本日志不进入首页或当前阶段导航，后台留存供追溯；没有当前有效产出的阶段标为待开展，不链接旧结论。当前建议与待确认项明确标注，不因页面清理而升级为已确认。主页及沿用的阅读入口同步指向同一当前内容。
